# PaperNest – SEO Keyword Research Project

## Veda Technology: Basic Keyword Research

A submission-ready SEO keyword research project for **PaperNest**, an online stationery and paper-products business.

### Objectives
- Identify relevant SEO keywords
- Classify keywords by search intent
- Separate primary and secondary keywords
- Group related keywords
- Explain selection rationale
- Recommend suitable SEO page/content types

### Deliverables
- `documentation/PaperNest_SEO_Keyword_Research_Report.docx` – editable report
- `documentation/PaperNest_SEO_Keyword_Research_Report.pdf` – submission-ready report
- `PaperNest_Keyword_Research.xlsx` – keyword research spreadsheet
- `data/PaperNest_Keyword_List.csv` – CSV keyword list

### Search Intent
Informational, Commercial, Transactional, Navigational.

### Research Note
This is a strategic basic-research deliverable. It does not invent live search-volume, CPC or competition numbers. For a real SEO campaign, validate keywords with Google Keyword Planner, Google Search, Ubersuggest and Google Trends.
